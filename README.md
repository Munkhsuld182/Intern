# Financial Analysis Project (Internship)

This repository contains a structured financial analysis project prepared for a professional finance internship.

## Objectives

- Analyze the company’s financial position and performance
- Calculate key financial ratios
- Evaluate profitability, liquidity, and solvency
- Identify financial strengths and risks
- Provide recommendations for improvement

## Required Inputs

Use the company’s:

- Balance Sheet
- Income Statement
- Cash Flow Statement

## Analysis Framework

### 1) Profitability Ratios

- Gross Profit Margin = Gross Profit / Revenue
- Net Profit Margin = Net Income / Revenue
- Return on Assets (ROA) = Net Income / Average Total Assets
- Return on Equity (ROE) = Net Income / Average Equity

### 2) Liquidity Ratios

- Current Ratio = Current Assets / Current Liabilities
- Quick Ratio = (Current Assets - Inventory) / Current Liabilities
- Cash Ratio = Cash and Cash Equivalents / Current Liabilities

### 3) Solvency Ratios

- Debt-to-Equity = Total Liabilities / Equity
- Debt Ratio = Total Liabilities / Total Assets
- Interest Coverage = EBIT / Interest Expense

## Deliverables

- Ratio calculations in Excel
- Visual dashboards/charts for key trends
- Written assessment of strengths and risks
- Practical recommendations to improve financial performance

## Tools

- Excel
- Financial ratio analysis
- Data visualization
